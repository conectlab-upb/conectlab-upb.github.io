    Ce este Home Assistant OS

    HAOS este un sistem de operare minimal, construit pentru Home Assistant. Conține Supervisor (gestionează actualizări, add-on-uri, backupuri) și Home Assistant Core (aplicația Python cu integrările, automatizările și dashboardurile). Este metoda de instalare recomandată pentru majoritatea utilizatorilor. Alternativa Container (Docker) nu are Supervisor și nici magazin de add-on-uri.

    Cerințe minime (orientativ)
    • 2 nuclee, 4 GB RAM recomandat (2 GB minim), disc de 32 GB.
    • Pe Pi: card SD A2 sau, de preferat, SSD; alimentator oficial; cablu Ethernet la prima pornire.
    • Pe mașini virtuale: firmware UEFI/EFI obligatoriu. Imaginea HAOS nu pornește în modul BIOS.
    Porturi și adrese folosite
    • 8123 – interfața web și API Home Assistant (http://homeassistant.local:8123 sau http://IP:8123).
    • 8006 – interfața web Proxmox (https://IP:8006).
    • 1883 – broker MQTT (dacă folosești Mosquitto).
    • 22 / 22222 – SSH prin add-on-ul Terminal & SSH / depanarea gazdei HAOS.
    De ce IP fix (rezervare DHCP)

    După un restart al routerului, dispozitivele pot primi alte adrese, iar integrările care țin minte IP-ul (MQTT, invertoare, controlere) devin „unavailable”. Soluția recomandată: rezervare DHCP în router (MAC → IP), nu IP setat manual pe fiecare dispozitiv. Adresa o alegi din intervalul liber al routerului tău (în laborator, o primești de la cadrul didactic).

    Legătura cu instalația reală a laboratorului

    Laboratorul rulează Home Assistant atât pe Raspberry Pi 4, cât și ca mașină virtuală pe servere Proxmox. Tabloul T02 are un dashboard SCADA construit în HA. Instalarea din acest modul este primul pas pentru orice lucrare care folosește tablourile T0x.
